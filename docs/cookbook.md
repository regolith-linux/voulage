# Regolith Build Cookbook

## Making changes to `changelog`

Use [the Voulage action](https://github.com/regolith-linux/voulage/actions/workflows/update-changelog.yml) to automatically update the changelog.  Avoid manually updating as part of the associated fix or feature.

## Archive server

See [archive-server.md](archive-server.md) for the archive layout and the manual steps a release needs on the archive server.
